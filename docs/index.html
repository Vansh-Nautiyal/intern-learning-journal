Projects

AI Sign Language Detector

A real-time American Sign Language (ASL) alphabet recognition system built using MediaPipe, TensorFlow/Keras, OpenCV, and Streamlit. The application detects hand landmarks through a webcam feed and predicts sign language alphabets using a trained deep learning model.

Yatra Saarthi - AI Travel Planner

Yatra Saarthi is an AI-powered itinerary generation web application designed specifically for budget-conscious student travelers. Built using Streamlit and the Groq API, the platform generates personalized travel plans based on user preferences such as destination, budget, and duration.

BookSphere - Library Management System

BookSphere is a desktop-based Library Management System developed using Java Swing and SQLite. The application supports role-based access control for Admin, Operator, and Student users, allowing efficient management of books, borrowing, returns, and user records.

Image Split Into QR Codes

This project is a Python-based application that splits an image into four equal quadrants, converts each quadrant into an individual QR code, and later reconstructs the original image from the generated QR data. The project demonstrates concepts of image processing, data encoding, and QR-based data storage using Python libraries.

Stock Price Prediction using LSTM

This project is a machine learning-based stock price prediction system developed using Python, Streamlit, and LSTM (Long Short-Term Memory) neural networks. The application analyzes historical stock market data and predicts future stock prices using deep learning techniques.
