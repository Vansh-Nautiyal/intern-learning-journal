Projects

AI Sign Language Detector

AI Sign Language Detection using MediaPipe and Neural Network

This project is a real-time American Sign Language (ASL) alphabet recognition system built using MediaPipe, TensorFlow/Keras, OpenCV, and Streamlit. The application detects hand landmarks through a webcam feed and predicts sign language alphabets using a trained deep learning model. The project aims to improve communication accessibility by enabling real-time gesture recognition and demonstrates the integration of computer vision and artificial intelligence in assistive technology applications.

Yatra Saarthi

Yatra Saarthi - AI Travel Planner

Yatra Saarthi is an AI-powered itinerary generation web application designed specifically for budget-conscious student travelers. Built using Streamlit and the Groq API, the platform generates personalized travel plans based on user preferences such as destination, budget, and duration. The project focuses on simplifying trip planning through AI-driven recommendations, smart itinerary generation, and user-friendly design, making travel planning more accessible and efficient for students.

Book Sphere

BookSphere - Library Management System

BookSphere is a desktop-based Library Management System developed using Java Swing and SQLite. The application supports role-based access control for Admin, Operator, and Student users, allowing efficient management of books, borrowing, returns, and user records. The project was designed to streamline traditional library operations through a graphical user interface and database integration, providing an organized and user-friendly library management solution.

Image Split Into QR Codes

Splitting an image into QR Codes and Reconstructing it

This project is a Python-based application that splits an image into four equal quadrants, converts each quadrant into an individual QR code, and later reconstructs the original image from the generated QR data. The project demonstrates concepts of image processing, data encoding, and QR-based data storage using Python libraries. It explores an innovative way of securely storing and transferring image information through QR technology while maintaining accurate reconstruction of the original image.

Stock Price Prediction

Stock Price Prediction using LSTM

This project is a machine learning-based stock price prediction system developed using Python, Streamlit, and LSTM (Long Short-Term Memory) neural networks. The application analyzes historical stock market data and predicts future stock prices using deep learning techniques. It provides users with a simple interactive interface to visualize stock trends, model predictions, and market behavior, demonstrating the practical application of AI and time-series forecasting in finance.
